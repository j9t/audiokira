# Audiokira (Beta)

[![GitHub Sponsors](https://badgen.net/static/Support/Open%20Source/cyan)](https://github.com/sponsors/j9t)

Audiokira (¬Akira) is a browser-based audio frequency editor. It removes recurring frequency patterns—like electrical hum, HVAC noise, or tonal interference—from audio and video files, without uploading anything to a server.

Use Audiokira at **[j9t.github.io/audiokira](https://j9t.github.io/audiokira/)**.

For usage instructions, filter presets, tips, and limitations, see the “About Audiokira” section of the editor.
